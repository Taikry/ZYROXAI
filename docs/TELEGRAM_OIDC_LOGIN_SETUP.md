# ZYROX AI — Telegram Login OpenID Connect (OIDC) Setup & Integration Guide

## 1. Overview
ZYROX AI has been integrated with Telegram's official **OpenID Connect (OIDC) Authorization Code Flow with PKCE (`S256`)** for the authenticated bot **`@zyroxloginbot`**.

This replaces deprecated iframe widgets with modern OAuth 2.0 / OIDC security:
- **Authorization Endpoint:** `https://oauth.telegram.org/auth`
- **Token Endpoint:** `https://oauth.telegram.org/token`
- **JWKS URI:** `https://oauth.telegram.org/.well-known/jwks.json`
- **Issuer:** `https://oauth.telegram.org`
- **Scopes:** `openid profile`
- **PKCE:** S256 (`code_verifier` & `code_challenge`)
- **Account Identification:** Identified strictly by Telegram's permanent numeric subject ID (`sub`), NOT username.

## 2. BotFather Configuration (Action Required)

To activate login through `@zyroxloginbot`, register the following **Allowed URLs** in Telegram's [@BotFather](https://t.me/BotFather):

### Step 1: Open BotFather
1. Send `/mybots` to [@BotFather](https://t.me/BotFather).
2. Select your bot: **`@zyroxloginbot`**.
3. Select **Bot Settings** -> **Domain** / **Allowed Redirect URLs**.

### Step 2: Register Exact Allowed Callback URLs
Enter the following URLs (discovered from your production Render service and local environment):

```
https://taikry-ai-trading.onrender.com/api/v1/auth/telegram/callback
https://zyroxai.onrender.com/api/v1/auth/telegram/callback
http://localhost:8000/api/v1/auth/telegram/callback
http://127.0.0.1:8000/api/v1/auth/telegram/callback
```

> [!IMPORTANT]
> Telegram strictly enforces exact string matching for redirect URIs. Ensure `https://taikry-ai-trading.onrender.com/api/v1/auth/telegram/callback` is registered.

## 3. Environment Variables Configuration

Add the credentials generated by BotFather to your production environment (Render Dashboard -> Environment Variables) or local `.env` file:

```env
# Telegram Login OpenID Connect (OIDC)
TELEGRAM_LOGIN_CLIENT_ID=your_telegram_bot_client_id_here
TELEGRAM_LOGIN_CLIENT_SECRET=your_telegram_bot_client_secret_here
TELEGRAM_LOGIN_REDIRECT_URI=https://taikry-ai-trading.onrender.com/api/v1/auth/telegram/callback
TELEGRAM_LOGIN_ISSUER=https://oauth.telegram.org
TELEGRAM_LOGIN_JWKS_URI=https://oauth.telegram.org/.well-known/jwks.json
TELEGRAM_LOGIN_BOT_USERNAME=zyroxloginbot
```

### Current Status
When `TELEGRAM_LOGIN_CLIENT_ID` is empty, the application safely operates in `NEEDS_CONFIGURATION` status:
- API endpoint `GET /api/v1/auth/telegram/status` returns:
  ```json
  {
    "configured": false,
    "status": "NEEDS_CONFIGURATION",
    "bot_username": "zyroxloginbot",
    "required_env_vars": ["TELEGRAM_LOGIN_CLIENT_ID", "TELEGRAM_LOGIN_CLIENT_SECRET", "TELEGRAM_LOGIN_REDIRECT_URI"]
  }
  ```
- The frontend gracefully alerts users that configuration in `.env` is pending, without crashing or faking successful logins.

## 4. Security & Cryptographic Verifications

The integration passes 13 automated security tests covering:
1. **Cryptographic PKCE (S256):** Prevents authorization code interception on public and mobile networks.
2. **Server-Side Temporary State Cache:** Generates cryptographically secure `state` and `nonce` tokens with 10-minute TTL.
3. **Anti-Replay Protection:** State tokens are popped atomically on first use; replayed authorization callbacks are immediately rejected.
4. **JWKS Signature Verification:** ID tokens are verified against Telegram's official public keys (`oidc-1`, `oidc-es256-1`, etc.) supporting RS256, ES256, EdDSA, and ES256K.
5. **Claims Validation:** Strict validation of `iss`, `aud`, `exp`, `iat`, and `nonce`.
6. **Permanent Subject Tracking (`sub`):** Accounts are linked and identified by Telegram's permanent user ID (`sub`), safeguarding accounts if a user changes their `@username`.
7. **Automated 14-Day Free Trial:** New users registering via Telegram receive instant activation of the 14-day institutional trial.
8. **Account Linking:** Authenticated users can link their Telegram account without losing history or settings.
9. **HttpOnly Session Cookies:** Emits the standard `zyrox_session` cookie (`HttpOnly`, `SameSite=Lax`, `Secure` in production) with 30-day persistence.
